# 项目迁移：自选目标位置 + 会话与产物整体打包

## 用户目标

把一个项目在本应用内的全部资产——会话记录与项目目录下的产物文件——打包成一个可迁移文件，在另一台设备或不同检出路径上导入时**自主选定目标位置**，导入后会话出现在目标项目下且可直接续跑。

## 验收条件

1. **导出**：项目右键菜单可导出「项目迁移包」（加密 `.ofar`，口令可留空）：包含该项目全部会话记录 + 项目目录文件树（默认排除 `.git`/`node_modules`/`.vetta`，可整包开关）；零会话项目给出明确提示；远程（SSH）项目明确报不支持。
2. **导入**：现有「导入会话归档」入口自动识别迁移包并进入迁移向导：预览（源路径、会话数、产物文件数与体量）→ 选目标（现有项目或新路径）→ 冲突策略（默认不覆盖已有文件）→ 执行 → 结果报告；执行后目标项目侧栏即时出现迁移会话，打开可继续对话（cwd 已重写为目标路径，见 ADR-0147）。
3. **幂等与安全**：同一迁移包重复导入同一目标幂等跳过；换目标视为新副本；口令错误/包损坏明确报错且不落盘；产物恢复不静默覆盖用户文件；体积超限（单文件 >512MB、总量 >4GB）导出前明确失败。
4. **兼容**：v1 会话归档（单会话/项目会话导出、既有导入流程）行为与字节不变；迁移包在旧版本上明确「版本不支持」而非损坏误报。
5. 技术合同见 [ADR-0147](../../docs/adr/0147-project-migration-archive-v2.md)；实施合同见 TASK-0361。

## 不做

- 不做消息/工具调用历史内绝对路径的重写（历史是事实，见 ADR-0147 取舍）。
- 不做产物增量/去重打包；远程项目迁移（产物在远端）留待后续按 SSH 传输（REQ-0012 基建）立项。
