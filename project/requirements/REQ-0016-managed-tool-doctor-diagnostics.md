# 受管编码工具环境自诊断（doctor）

## 用户问题与目标

编码 Agent 依赖的受管外部工具（fd / rg）由运行时按「缓存目录 → PATH → 自动下载」解析。工具缺失或行为异常时，用户与支持排障目前只能靠日志推断实际命中的是哪个二进制、什么版本、为何缺失。目标：提供**只读自诊断**能力，一键获知每个受管工具的实际来源（缓存 / PATH / 缺失）、路径、版本与离线状态。

## 功能范围与不做项

**做**：

- 两条既有出口：终端一条 `doctor` 子命令打印工具解析表；Desktop「导出诊断包」内附带同等解析记录。
- 记录为纯静态检查：不触发下载、不产生网络请求。

**不做**：

- 不做自动修复或代下载（doctor 只报告，不改变环境）；
- 不覆盖 SSH 远端项目的远端工具解析（本地视角）；
- 不新增设置界面、不新增 IPC 通道。

## Given / When / Then

- Given：某工具已由缓存目录提供；When：执行 doctor 或导出诊断包；Then：该工具记录来源=缓存、含路径与版本，且检查过程未 spawn 该工具以外的探测。
- Given：某工具仅存在于 PATH；When：同上；Then：记录来源=PATH，版本取自该工具自报的版本输出。
- Given：某工具既无缓存也不在 PATH；When：同上；Then：记录来源=缺失，并如实标注当前是否处于离线模式。

## 必须保持的不变量

- 既有工具解析与自动下载行为完全不变（诊断是旁路只读面）；
- 诊断导出不引入网络副作用与额外用户可见文案负担；
- 诊断结果只反映检查时刻的本地事实，不缓存结论误导后续排障。

## 验收标准

- 终端 doctor 命令对每个受管工具输出 来源/路径/版本/状态 一行，命令独立可用（不依赖 Desktop 运行）；
- 诊断包内含结构化解析记录文件，内容字段与 doctor 同源；
- 两出口的检查路径有自动化测试覆盖（含缓存/PATH/缺失三分支）。

## 风险与失效条件

- 版本标记为新增落盘事实，存量已下载缓存首次诊断时无标记，需定义回退口径（TASK-0307 定死）；
- 若未来工具集或解析优先级变化，doctor 记录字段需同步扩展，否则报告失真。
