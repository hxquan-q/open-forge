# Windows 电脑操作

## 用户问题与结果

用户希望 AI 操作本机已有 Windows 应用，而不局限于内置浏览器。独立「电脑操作」板块提供开启、目标选择、会话授权、观察、执行、暂停、接管、停止与恢复窗口的完整闭环。**安装 Vetta 后即可使用，不要求另装或配置 Python/winhands。**

来源：工作区 `D:/Coding/WorkSpace/Vetta/computer-use-handoff.md`；2026-11-10 用户确认开箱可用，并授权主仓实施及独立本地分支，不允许远程 Git 或修改主仓/工作区外文件。

## 范围

- Windows 首版，能力默认关闭；观察与输入授权分离，授权按会话且不跨重启沿用。
- 复用 winhands 执行基础；随应用分发兼容执行后端和许可，不依赖开发机绝对路径或系统 Python。
- Vetta 自身隐藏/唤回、置顶独立控制；隐藏不等于暂停或结束。托盘提供隐藏后可达的停止与找回入口。
- 目标窗口隐藏、恢复查看、隐藏清单和异常恢复；不删除隐藏需求。
- 隐藏后台兼容动作继续；必须前台的操作默认暂停并要求用户明确许可，不静默抢焦点或发送错误输入。
- 同一交互桌面由一个会话拥有输入控制权；用户可随时暂停、接管、停止；撤销使排队动作失效并释放持有输入。
- 明确区分后端可用性、任务状态、当前目标和控制权；非 Windows 提示不支持而不加载 Windows 后端。

## 不做什么

不引入虚拟机、独立桌面或远程 relay；不替换 browser_tab；不声称任意 Python 是沙箱、窗口选择是系统隔离或任意软件隐藏后必可继续操作。不操作用户真实桌面/Provider 验证，不修改现有 winhands 或用户级配置，不发布或推送。

## Given / When / Then

1. Given 新装 Windows Vetta 且无 Python/winhands，When 打开电脑操作并开启，Then 使用随包后端，展示可选目标，无额外运行环境配置。
2. Given 用户选择目标和会话并仅授权观察，When AI 观察再尝试输入，Then 返回观察结果且输入被拒；授权输入后才执行。
3. Given 已授权会话，When 观察、执行、隐藏目标、恢复查看、停止，Then 连续状态一致，恢复不是结束，停止后无排队动作落地。
4. Given Vetta 隐藏且任务存在，When 从托盘停止/找回，Then 能停止任务、释放输入、找回由 Vetta 隐藏的窗口。
5. Given 隐藏目标需要真实键鼠或截图无效，When AI 继续，Then 明确暂停等待前台许可，不盲点、不伪成功。
6. Given 多会话竞争或用户接管，When 新动作到达，Then 无冲突桌面输入且旧授权不可继续落地。

## 必须保持与验收

保留 browser_tab、现有 Agent 角色/工具结果图片/错误/取消/usage 合同及包依赖方向。所有权限在宿主检查，不从屏幕或模型文本扩大授权。UI 文案 i18n，快捷键可配置。窗口身份验证包含进程/实例，防止句柄复用；只恢复由本功能隐藏的窗口及原始展示状态，提供重启找回。

工程验收包括代表性连续用户流程、IPC/工具/进程取消合同、隐藏窗口生命周期、组件交互、离线资源打包/后端完整性检查与根完整 check。真实桌面兼容性和真实模型效果单列未验证，人工接受后才能关闭需求。

## 风险与失效条件

软件 UIA/渲染兼容性不同；隐藏后不可观察需明确错误；进程强停不能虚构已完成副作用回滚。依赖分发必须带许可，构建必须在后端缺失时失败而非产出缺功能安装包。崩溃后通过持久隐藏台账找回，不承诺系统崩溃即时恢复。
