# 智能客服页面视觉打磨

## 用户问题

智能客服页顶部留白过大（页头与内容整体偏下，一屏能放的对话少）；回答生成时文字整块出现，缺少书写节奏；提交后长时间空白等待；侧栏收起是硬切。2026-10-20 实机复查发现：仅收内边距没解决「顶部一大坨白」——真正的元凶是页面自带的一条 48px 纯空白拖拽带。

## 用户结果

页面顶部留白收掉（含删除 48px 空白带）；历史会话栏上移；回答生成时新字符逐个淡入浮出；等待首字时显示「思考中」三点动画；侧栏收起/展开平滑滑动；副标题改为「由小爱酱知识库为你回答」。

## 范围

1. **布局**：左右 32→12px、页头下边距 16→8px、内容行下边距 32→12px；**删除页面自带的 `drag-region h-12` 空白带**（窗口拖拽由外壳页头承担）。
2. **逐字入场**：尾部窗口（64 字符）内的新字符逐个淡入上浮；历史/用户消息不重播动画。
3. **思考三点**：等待首字期间显示，首字到达即消失；走宿主统一动画引擎；尊重减少动效。
4. **收起动画**：宽度滑动 + 淡出，动画结束整栏卸载；尊重减少动效。
5. **文案**：副标题 zh/en。

**明确边界**：纯渲染层，不动数据流/IPC/主进程；不改外壳组件；外壳页头（44px，app 级）不在范围。

## 验收

工程侧：验收标准见 `docs/devflow/weknora-chat-visual/01-spec.md`（AC-1~15）与 `docs/devflow/weknora-top-whitespace-fix/01-spec.md`（AC-1~5）；测试与 OCR 审查已闭环。人工侧：实机观感待用户确认。
