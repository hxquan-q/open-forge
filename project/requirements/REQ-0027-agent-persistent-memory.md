# Agent 全局与项目持久记忆

## 用户问题

用户需要在重启、更换会话、切换项目或使用不同 Agent 后，延续合适的偏好、项目决定与已验证经验；不应重复讲述同一背景，也不应受到其他项目、旧事实和失败尝试的误导。现有门控记忆主要面向 IM 的小型文件快照，不能等同于 Desktop 已具备上述能力。

## 用户结果

1. 用户明确要求记住的内容可跨会话找回，能说明来源与适用项目。
2. 可选择自动整理正常工作的经验，既能找回事实，也能减少后续任务的重复失败。
3. 用户可以查看、纠正、忘记和暂停记忆；关闭、失败和删除状态不会被伪装成成功。

本记录确认产品目标；[PLAN-0021](../plans/PLAN-0021-agent-persistent-memory.md) 为候选实施方案。已按用户要求建立TASK-0367–0389及依赖/验收合同，尚未进入功能实施。

## 范围

- 用户全局、项目、任务/分支三层作用域；Agent 身份和团队授权另行约束可见性。
- 稳定的项目关联、同仓 Worktree 的受控共享、项目迁移时的记忆身份处理。
- 明确记住/纠正/遗忘，来源与修订历史，当前/历史事实查询，可靠的自动捕获和检索。
- 默认本地持久化；关键词和可选语义检索；受预算约束的上下文注入。
- Desktop 为首个交付宿主，CLI 使用相同记忆合同；现有 IM 兼容单独验收后再接入，不能自动并入个人全局空间。
- 面向用户的查看、纠正、删除、禁记、导出及状态反馈；测试同时覆盖事实召回和连续任务收益。

## 不做什么

- 不在本次方案阶段修改运行代码、安装依赖、执行真实模型评测或迁移真实历史。
- 首版不做跨设备实时同步、服务端团队记忆、全库知识图谱、参数/KV 记忆和自动修改 AGENTS/Skill。
- 不把已有所有历史静默批量抽取，不把项目数据或 IM 聊天身份静默提升为全局用户偏好。
- 不承诺所有旧事实自动正确合并，不把厂商 benchmark 当作本产品验收结果。

## Given / When / Then

| Given | When | Then |
|---|---|---|
| 用户在项目 A 明确保存约定 | 重启后开启 A 的新会话继续工作 | 找回正确约定并可查看出处，无需重复讲述 |
| A、B 项目具有同名模块和相反约定 | 在 B 提问或执行任务 | 不取得 A 的私有事实；适用的用户偏好仍可受控使用 |
| 同仓两个 Worktree 有不同实验 | 在任一 Worktree 继续任务 | 已确认项目事实可共享，另一分支假设不被当成当前事实 |
| 新事实更正旧值或迟到报告过去变化 | 问当前值、过去值或当时已知信息 | 区分有效时间和获知时间；未确定冲突能表达不确定性 |
| 用户忘记一条记忆 | 重开旧会话、重建索引或重试旧任务 | 该记忆全部版本及受控派生物不可再召回，旧来源不会自动重抽取恢复 |
| 助手说工作成功但工具失败/取消 | 自动整理本轮经验 | 不保存成已验证的成功事实，也不持久化 thinking 或系统指令 |
| 模型、索引或存储不可用 | 用户继续交互或明确要求记住 | 主交互可恢复；明确写入如实报告失败，自动失败有可查看状态 |
| 项目迁移到另一位置或复制为新项目 | 通过明确的迁移/复制流程导入记忆 | 迁移保持已确认关联，复制隔离；不以重写全部历史路径实现身份迁移 |

## 必须保持

- 现有用户/仓库指令与工具授权优先；记忆不扩权，不把外部数据当新指令。
- Provider 角色、错误、取消、usage、stop 与 Turn generation 语义；自动记忆不是成功/失败判定的新主人。
- IM 既有 `/new` flush、日期 cwd、rollover 与消息路由合同；通用 Desktop 记忆不能自动打开 IM rollover。
- ConversationDocument 继续是对话事实源，知识库继续承担文档语料；记忆派生层不取代它们。
- 不静默覆盖/删除用户 MEMORY.md、JOURNAL.md；导入、回滚和不兼容状态必须明确。
- 本地保存不暗示完全离线；模型调用、模型下载、遥测和数据外发分别说明且服从用户选择。

## 验收标准

- 正常创建、恢复、切项目的完整入口证明功能实际启用，不能仅凭 factory、Profile 字段或内部单测判定交付。
- 三层 scope、来源、修订、时间查询与明确遗忘通过合同和宿主流程验证；隔离/未授权外发/删除恢复集合没有已知违规。
- 中文短词、路径、标识符、错误码、自然语言改写分别检验；无语义模型时明确降级而不影响本地基本能力。
- 用户能识别已保存、处理中、失败、暂停与部分可用，并从同一入口查看/纠正/遗忘。
- 固定模型与预算的连续任务对照记录成功率、步骤、重复失败、召回、尾延迟和全生命周期费用，未证明净收益的机制不扩大启用。

## 风险与失效条件

自动抽取、双时态和分支关联都可能出错，需保留证据与人工纠正；本地索引/原生依赖需验证多平台打包。账号身份、团队分享或项目迁移协议变化时重评授权与关联。跨设备备份、用户另存导出与原始对话的清除不能冒充已由“忘记记忆”自动覆盖，须在操作语义中说明实际边界。
