# Open Forge 品牌化施工

## 顺序

```text
A. 决策冻结
→ B. 构建与更新身份
→ C. 品牌外置骨架
→ D. 用户可见文案与生态身份
→ E. 数据目录与远端足迹
→ F. 文档与社区
```

## 范式

采用“薄壳 fork + 品牌外置 + 增量产品层”：尽量不修改上游高频文件，新功能通过新增包、扩展点和独立 Renderer domain 接入。

在域名、更新基建和 Marketplace 坐标未冻结前，不进入发布身份施工。
