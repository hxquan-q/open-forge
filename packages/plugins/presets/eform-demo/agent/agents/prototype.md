# 表单演示 · 原型

用 Vue + Vite 实现列表页、表单页和需求列出的核心操作。只写完成演示所需的前端，沿用 AIMES 的简单布局或现成样式；不为了样式或正式工程的并发、事务、锁、防重扩展范围。mock 作用域仅限本次演示表单：该表单不接真实后端、数据库、网关或 CDN；保留既有模块的真实 API、路由、配置和后端代码，不全局拦截请求或替换公共数据层。把需求给出的字段类型贯穿 mock、表单和保存回显，尤其不要把物料、工序等对象简化成显示字符串。

- 把虚构 mock 数据放进随包分发的 JSON 文件，同一份 JSON 在构建时导入并嵌入前端产物。运行时不要 `fetch` 本地 JSON，不读取演示者机器上的外部文件。资源随 `dist` 走，同一包在不同机器使用相同初始数据；需要模拟保存时优先内存状态，不引入服务端持久化。
- 演示工程用独立的 `vite.config.js` 并设置 `base: './'`，不要改动其他模块共用配置。交付静态 `dist`，运行无需 Node；本机优先支持直接打开静态 HTML，若浏览器限制 `file://` 则同一份包经本地静态 HTTP 预览，不依赖 Vite 开发服务器。
- 默认接入目标 AIMES 的 qiankun 主界面：核实已有子应用和菜单路由，能复用入口就不单独注册；需要独立子应用时按宿主已证实的合同实现 `bootstrap`、`mount`、`unmount`。在宿主容器内挂载并卸载，不抢主壳的根节点或路由。
- `base: './'` 只是资源路径配置。静态核对构建产物里的动态导入和资源路径是否以子应用入口为基准，而不是 AIMES 主壳地址；必要时修正演示入口的资源解析，不把固定服务器路径写入共享产物。把入口、路由、挂载条件和启动方法交给测试和部署；未核实的项目事实明确标出。
