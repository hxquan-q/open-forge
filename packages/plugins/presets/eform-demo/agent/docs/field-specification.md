# 字段规格与基础资料（演示）

接收附件中的原始字段或自然语言需求，输出演示唯一的一份字段规格，供原型和测试共用。不重新解析附件，不查库，不推断生产 API、DTO、数据库列或权限。

## 统一类型

| 规格类型 | 语义与确认项 |
|---|---|
| `string` | 明确的文本，如姓名、名称、编码、编号、批号、备注。数字外观的编码仍是文本，保留前导零。 |
| `number` | 明确的数量、金额、比例或普通整数；区分整数和小数，按核心操作确认单位、允许范围和舍入。 |
| `boolean` | 是/否，缺省和未填写不自动等于否。 |
| `date` / `datetime` / `time` | 日期、日期时间、时刻分别定义；JSON 可用约定格式的字符串表示，但业务规格不降为普通文本。涉及跨机器日期展示时固定有意义的时区与格式。 |
| `object` | 关联实体，如物料、工序、组织、供应商、可选择的人员。无法确定是对象还是文本时默认对象，标注为演示假设；不覆盖已明确的其他类型。 |
| `array<T>` | 明细、多选等已确认的集合；说明元素字段、有无顺序及对应的核心业务规则。 |

## 基础资料对象

- 区分选择对象与展示值：`material` 是物料对象，`material.name` 才是文本。列表可显示名称，表单选择、mock 保存和回显不能把物料压成名称或 ID 字符串。明确只叫“物料编码”且没有实体选择或联动语义时，它是文本。
- 有当前项目中已核实的参考形状就优先参考；没有时按演示需要定义最小对象，例如 `{ id, code, name }`。这是 mock 形状，不承诺正式接口也用这些键；未选中、空对象、空字符串不要混用。
- 固定短枚举说明值类型、值与标签，不伪装成远程基础资料。普通签字栏按原语义记录，不自动生成电子签。

## 原件证据与交接

原件标记只是证据。是/否、整数/小数、日期/时点按语义转为上表类型；“品名”等可能是展示属性，也可能指向从物料对象选择，结合是否有选择、引用或联动判断。不把原件标签当数据库列名；关联标记不作为页面前缀。

短规格写清标签、字段键、唯一类型、对象/明细形状与虚构样例。只为影响核心流程的字段补齐取值来源、默认值/枚举、公式、单位与精度、空值、联动及可见结果。保留已确认、演示假设和待核实的区别。例：选定 `material` 对象后带出显示单位，数量 `2` 保持数值，保存后列表显示 `material.name`，重新进入表单仍选中原对象。
