# @vetta/skill-presets

## 数据库问数与分析

内置 `database-analysis` 技能复用已经配置的数据库 MCP 连接器，不新增连接或读写权限。
在 Desktop 的「能力 → 发现」添加并配置「通用数据库」，确保当前智能体可使用连接器与
「数据库问数与分析」技能，然后可直接提问：

- “统计 8 月和 9 月已支付订单收入，比较变化，并画趋势图。”
- “按渠道拆开，哪些渠道贡献了变化？”
- “查上周新增用户，说明去重方式、时区和过滤条件。”

问题会先确认口径，再查相关结构和只读聚合数据；SQL、数据范围与限制随结论提供。
图表/报告复用已有画布能力；没有画布工具时返回表格，不影响问数。此能力不是独立 BI
页面，自然语言到 SQL 的正确性仍需模型结合真实表结构与业务定义判断。

可选的零依赖 Node 分析脚本仅处理查询后的汇总 JSON，不访问数据库。输入合同、数值
精度限制、空值及截断处理见 [分析助手](database-analysis/references/analysis-helper.md)。
高精度金额和加权指标在数据库内计算；未知值不会自动补零。
