# ADR-0154：Windows 电脑操作使用随包私有后端与主进程授权控制面

## 状态

已接受并实施（2026-11-10，REQ-0033 / PLAN-0031 / TASK-0482；人工桌面验收另记）。

## 背景与备选

用户要求安装后即可操作本机既有应用，并保留 Vetta 自身显隐/置顶、目标窗口隐藏恢复与用户接管。WinHands 0.4.1 提供成熟 UIA/输入原语，但原 MCP `run(code)` 是任意 Python，并包含脚本加载、shell、自动前置与物理回退。直接注册为全局 MCP 无法兑现“仅观察”和后台不抢焦点，也无法把会话撤销等同于真实停止。

外部系统 Python/winhands 或首次联网安装违反开箱可用要求；重写完整 UIA/输入引擎与建设虚拟机/独立桌面不符合“先有再好”。选择复用经裁剪的原语，随包分发私有运行时。

## 决策

1. Windows x64 随包 `Resources/computer-use/` 包含 CPython 3.12.10 embed、固定哈希的 uiautomation/comtypes/Pillow、受限 WinHands 原语、Vetta worker 和实际依赖许可。安装后无下载、无 PATH/Python 查找、无用户级 MCP 注册。其他平台不打包/启用该后端。
2. `prepare-computer-use.mjs` 验证下载哈希和归档路径，生成逐文件完整性 manifest；Windows `prepare-pack.js` 强制准备、验证并复制到 asar 外，缺失或损坏阻断打包。开发入口复用同一资源准备，不存在开发机 G 盘路径依赖。
3. 模型只看到结构化 `computer_use`，通过现有 Session Extension host function 到 Desktop 主进程；私有后端继续复用 `StdioMcpClient` 处理握手、传输、限额与进程生命周期，不另造 Agent Loop。后端两个私有协议入口 `computer_action` / `stop` 不进入用户 MCP 目录。
4. 默认关闭；每次应用启动重新授权。主进程绑定真实 runtime session 与用户选定窗口，分观察、后台 UIA、允许前台输入三档。模型不能选择窗口、改变授权或恢复窗口来获取前台能力。输入动作沿既有工具风险/审批链提升为 L3，且整面为 exclusive；宿主另外仲裁所有会话的实际桌面控制权。
5. 后台 invoke/fill 仅调用 UIA pattern，失败不切前台、不模拟输入。物理点击/按键/滚动必须有前台许可、可见目标及实时焦点/命中检查；用户真实输入可使后端让出控制。Vetta 自身可见窗口在物理输入期间临时隐藏并以不抢焦点方式恢复，避免“截图排除了主窗，但点击落在主窗”。
6. HWND、PID、进程创建时间、类和映像共同参与身份；额外使用随 HWND 销毁自动移除的 Win32 property nonce 区分同进程同类窗口的句柄复用。验证不创建缺失 nonce。标题可正常变化。该标记不能作为针对恶意本机软件的系统安全隔离声明。
7. 元素引用绑定最新观察与具体窗口；坐标引用绑定截图版本、时间、尺寸、位置和画面摘要。PrintWindow 不可靠时不以屏幕像素回退。owned dialog 在受控 owner 链内跟踪；UIA 滚动必须命中该元素窗口，根截图不能点击遮挡它的另一个弹窗。
8. 取消不仅停止等待：私有 stop 在当前执行与 held-input 释放结束后才回复。停止未确认时保持失败关闭，不交接给另一个会话。退出尽力恢复并关闭后端，不以进程退出伪称释放回执成功。
9. 隐藏台账在用户状态目录原子写前保存，以避免 hide 后崩溃却无找回信息。只恢复仍匹配原窗口实例、且当前确实隐藏的窗口，已被用户恢复或未实际隐藏的不重复 ShowWindow；恢复错误保留记录。重启后不自动接管旧任务，提供页面和托盘找回。
10. 独立页面的业务连接留 Desktop，纯展示 recipe 位于 theme-ui；主进程原生窗口/托盘控制走薄 IPC，不作为通用 Runtime Host 的平台无关方法。系统停止/唤回键进入既有可配置快捷键表并只注销自己的注册；托盘作为快捷键不可用时的入口。

## 后果与验证

安装包增加约几十 MB 的私有运行目录；无需安装完整上游 MCP/视觉/OCR/记忆依赖。UIA、隐藏渲染、管理员窗口、动画画面和 Windows 输入权限仍存在兼容边界，不能承诺所有应用后台可用。worker 不执行上游 server、memory、shell 或用户 Python，仍不宣称 OS 沙箱。

以真实内部装配和假的 OS/进程边界验证权限、取消、连续操作、窗口恢复、UIA 拒绝回退、截图过期与组件交互；私有运行时自检只导入依赖，不观察真实桌面。实际软件兼容性、原生焦点/钩子、DPI/多屏和安装后人工操作需要另行授权验收，软件合同测试不替代这些证据。

回滚：停用功能、先找回隐藏窗口，再回滚原子提交；不删除未处理的恢复台账。未来新平台、不同执行后端或系统级窗口隔离成为硬需求时，另立合同，不扩大此任意 Python 接口。
