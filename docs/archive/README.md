## 原位保留的证据链

以下目录包含历史与现行工程记录，仍有代码、术语、Task 和文档入链。为保持可追溯性，不整体移动；沿本文索引查阅，并按每篇日期、状态和源码锚点判断适用范围。

- [架构决策 ADR](../adr/README.md)：保留决策原因与演进过程，部分合同仍生效。
- [Agent 研究和实施记录](../agent/) · [模型研究](../ai/) · [适配研究](../adapter/)：保留真实仓库坐标、提交和分析上下文。
- [性能测量快照](../desktop/preformance/README.md)：只代表记录的环境与日期。
- [早期调研归档](../../exprot/)：新需求、任务和结论写入 [Project](../../project/README.md)，不在旧目录继续维护。

当前文案约定见 [user-facing-copy.md](../user-facing-copy.md)，使用与开发入口见[文档导航](../README.md)。归档只保存证据，不作为新功能验收或发布依据。
