## 5. ⚠️ 需要你做的事

**① 同步这批改动并重新部署。**(本次版本号仍是桌面端 `0.1.3`;打包与发布需另行授权,不由 Agent 触发。)

**② 演示前请先看 [`weknora-connector.md`](./weknora-connector.md) §4** —— 那里记了**两个不影响本连接器、但会直接毁掉演示**的坑:

- 名为 `Allstar智能助手` 的智能体,其绑定的模型凭据已失效(调用会返回 401)。
  **用它会直接失败**;文档里给了精确的 `model_id` 定位与可用的备选智能体。
- 引用角标在智能体路径**非确定出现**(模型自行决定是否引用);已渲染为可点击角标(REQ-0022),无角标的回答属正常。

**③ 配置凭据时注意用「租户 API Key」**,不要用「平台 API Key」—— 后者调会话接口会返回 409。文档 §3 有创建步骤。
