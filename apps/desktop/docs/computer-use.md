# 电脑操作（Windows x64）

## 使用

Windows 完整安装包自带运行后端，**不需要安装或配置 Python、winhands 或 MCP**。电脑操作默认关闭；每次重启后需要重新授权。

1. 从侧栏「更多」打开「电脑操作」，也可以将它置顶。
2. 开启电脑操作，选择一个已经打开的应用窗口。
3. 核对「本次准备授权给」的对话名称，选择权限并点击「授权此对话」。
   - **仅观察与指导**：允许读取目标应用，不允许输入。
   - **协作：仅后台操作**：允许应用支持的 UIA 操作，不会自动回退为真实键鼠。
   - **连续操作：允许占用键鼠**：明确允许使用前台键鼠；检测到动作期间的真实输入冲突时会让出控制。准备直接修改目标应用时，建议先用「我来接管」明确暂停。
4. 返回对话下达任务，例如「先观察应用，告诉我有哪些可操作控件；在我确认后再填写内容」。工具名为 `computer_use`，应用内浏览器仍可使用 `browser_tab`。
5. 可随时暂停、接管或结束。「允许继续」恢复本功能授权，不自动新建模型回合；如果 AI 已结束回合，请返回对话发送「继续」。切换授权对话前，必须结束原对话的控制权；「本次准备授权」和「实际控制权」分别显示。

## 窗口显示与找回

- 「隐藏主窗口」只隐藏 Vetta，不等于暂停、结束或退出；置顶偏好独立保留。
- 隐藏后可用系统托盘唤回主窗口、停止电脑操作或找回应用。停止和唤回键可在「设置 → 快捷键」调整（默认 Ctrl+Alt+Q / Ctrl+Alt+V）。快捷键被其他软件占用时使用托盘。
- 「隐藏目标窗口」会跟踪该窗口及其 owner 链中的相关弹窗，不按进程名隐藏所有窗口。
- 「恢复查看」不结束授权；用户接管后再点继续，AI 才会继续操作。结束任务恢复由本功能隐藏且仍匹配原实例的窗口，不重置用户已自行恢复的窗口。
- 隐藏前原子记录恢复信息。应用异常退出后，下次打开可从页面或托盘找回；不会自动恢复上一轮 AI 控制权。记录位于 Vetta 状态目录的 `computer-use/hidden-windows.json`，在找回完成前不要删除。

## 兼容与安全边界

并不是所有应用在真正隐藏后都能执行或截图。没有相应 UIA pattern、目标失效、画面不可靠或必须前台操作时，功能会暂停或明确失败，不静默抢焦点。前台操作需要先恢复目标，并由用户重新授权合适的权限。

截图仅使用目标窗口的 PrintWindow，不以其他窗口的屏幕像素替代。坐标操作使用最新截图的本地图像坐标；旧引用、窗口移动、画面变化和过期截图会被拒绝。截图需要支持图像的模型，文本模型仍可读取可访问性树。

管理员窗口、游戏/独占渲染、某些 Electron/自绘应用、动画画面和系统权限限制可能不兼容。严格的画面一致性检查可能要求 AI 重新观察。Vetta 自身的可见窗口会在物理输入时临时让位，避免置顶遮挡导致错误点击。

操作可能改动应用数据、发送信息或触发外部行为，重要动作仍经过对话审批。同一 Vetta 实例内的对话统一仲裁控制权；不要同时运行其他桌面自动化或远程输入工具，它们不受本功能统一仲裁。工具不接受任意 Python/shell；窗口选择也**不是操作系统级沙箱**。强制杀进程或系统崩溃时不能保证即时清理；停止回执未确认时不会允许后续动作或交接到另一个对话。

## 开发与验证

在主仓中：

```bash
bun run --cwd apps/desktop prepare:computer-use
bun run --cwd apps/desktop test:computer-use-native
bun run --cwd apps/desktop verify:computer-use
```

资源写入 `apps/desktop/resources/computer-use/`，依赖下载缓存位于同级 `computer-use-downloads/`，均不提交。开发启动和 Windows 打包会自动准备资源；Windows 打包必须通过哈希与完整性验证，不能静默产出缺少后端的安装包。运行时完全不联网安装依赖。

`verify:computer-use` 只验证真实随包解释器、依赖导入、私有 MCP 握手、非法输入拒绝和停止回执，**不枚举窗口、不截图、不注入输入**。原生桌面、DPI/多显示器、具体软件隐藏兼容性、真实模型任务和完整安装体验需要另外授权验收；这些不是单元测试已证明的结果。

依赖锁与原始来源哈希在 `native/computer-use/dependencies.json`；许可随 `Resources/computer-use/licenses/` 及原样 wheel 的 dist-info 文件分发。架构见 [ADR-0154](../../../docs/adr/0154-windows-computer-use-bundled-backend.md)。
