title: Configure models
description: Add a preset or custom provider, verify its connection, and choose a default model for sessions and tasks.
---

{/* Modified by The Open Forge contributors. */}

Open **Settings → Model configuration**. Select a preset provider, enter the API key, pull the available models, and set one as the default. For a custom server, specify its API type, Base URL, model ID, and credential explicitly.

Pulled model lists are not auto-selected: tick the models you need (or use **Select all** / **Deselect all**) before adding. The **Test availability** action on each saved custom server sends a lightweight `GET {Base URL}/models` request and reports latency and model count inline; 401/403 usually means a bad key, 404 a wrong Base URL path.

## Verification checklist

- Use a short test request before starting a large task.
- Confirm the selected model supports the context and tool behavior you need.
- Keep the API key out of prompts, project files, logs, and issue reports.
- Record the provider and model ID when reporting a reproducible failure.

The local configuration file is `~/.openforge/agent/models.json`. Treat it as sensitive and use the UI for changes whenever possible.
