This page is for contributors and extension developers targeting this Open Forge repository. Check the target build's public exports, types, and documentation before choosing an integration.

Names such as `@vetta/*` and `@vetta-org/*` retain compatibility identities. Registry packages with the same name can follow a different version line. Use matching source and tooling for this fork's additions, and verify externally published packages against the target build.

| Need | Recommended entry |
| --- | --- |
| Add instructions and a repeatable workflow | Skill |
| Connect an external tool or data source | MCP |
| Extend Open Forge UI, files, messages, or host actions | Plugin |
| Embed an Agent in a TypeScript process | SDK |
| Drive an isolated or language-independent process | RPC |
| Run one task from a script | CLI |

Use only public package exports. Do not import from `@vetta/coding-agent/src/**` or another package's private source directory.

Read [SDK API reference](/developers/sdk-reference/) for entry points, lifecycle rules, and compatibility guidance.
