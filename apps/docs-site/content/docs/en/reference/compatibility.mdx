This matrix describes implementation and build targets in this repository, not the availability of released installers for every platform. Check the selected release's assets, tenant, and service configuration; companion mobile and remote-control features have separate preview limits.

| Capability | Windows | macOS | Linux | Android |
| --- | --- | --- | --- | --- |
| Desktop workspace and Agent | Supported | Supported | Supported | — |
| Models, MCP, knowledge, batch, automation | Supported | Supported | Supported | — |
| Desktop IM gateway | Build-dependent | Build-dependent | Build-dependent | — |
| Application snapshots | — | Supported | — | — |
| Desktop remote pairing | Developer preview | — | — | — |
| Mobile remote Desktop view | — | — | — | Developer preview |

Default source development runs lite: no cloud account, subscription, or hosted model catalog, with local sessions, BYOK, and GitHub ability sources. Full includes cloud client integration and requires a distributor-configured compatible backend. The business backend is maintained in a separate private repository; the build option does not establish an available login, subscription, or cloud marketplace. Source availability is determined by synchronization results.

Status labels mean: **Stable** is intended for normal use, **Beta** may change with platform or provider conditions, **Developer preview** is for development and validation, and **Internal-only** is outside the public contract.

When reporting a compatibility issue, include the Open Forge version, build source, OS version, CPU architecture, network conditions, and the last successful step. Never upload credentials, pairing data, webhook URLs, or an unredacted project directory.
